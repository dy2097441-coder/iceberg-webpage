What’s inside

Features

A compact operating system with a graphical desktop, built-in tools and networking capabilities.

🖥️

Desktop and apps

  • Windows, desktop icons and Start menu
  • Files, Terminal, Notepad, Settings, About and To-Do
  • Notepad Save As for .txt and .html files
  • Copy, cut and paste
  • Startup sound
🌐

Web browser

  • Loads real websites
  • Direct HTTPS, no proxy needed
  • Tries HTTPS before HTTP for typed names
  • Previews saved HTML pages
🔒

Networking and security

  • Own TCP engine with ARP replies
  • TLS 1.3 client written from scratch
  • Certificate checking
  • Mozilla root certificate trust store
💾

Install to disk

  • Copies Iceberg to a disk
  • Boots without the ISO afterwards
  • Keeps Home files on disk
  • Optional live try-out mode
🧊

Ice Store

Free apps made for Iceberg OS. Download .app files into Home/Downloads and open them from Files. Includes Calculator, Colors and Test apps.
