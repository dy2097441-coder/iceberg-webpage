System requirements

Iceberg is designed for modest x86 hardware and virtual machines. Check these requirements before booting.

Computerx86 PC or virtual machine, booting in BIOS or legacy/CSM mode. UEFI-only boot is not supported.
Memory64 MB RAM
GraphicsVESA VBE 2.0
InputKeyboard and PS/2 pointer (mouse)
Boot mediaCD/DVD drive or virtual optical drive for the ISO (about 350 KB)
Disk (to install)At least 64 MB, IDE or SATA (AHCI). Not needed for “Try It Without Installing”.
Network (optional)Realtek RTL8139 or AMD PCnet network card, as provided by VirtualBox.
Sound (optional)Intel ICH AC’97 audio controller. Intel HD Audio is not supported yet.

Iceberg has been tested in VirtualBox. It has not been tried on real hardware yet, so treat real PCs as experimental.
