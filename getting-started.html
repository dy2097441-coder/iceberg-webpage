Get started

Run Project Iceberg OS in VirtualBox. The project has been tested in a virtual machine and real-hardware use remains experimental.

Download the ISO from the GitHub releases page.

Create a new VM with 64 MB RAM or more, and add a hard disk of at least 64 MB (IDE or SATA).

Under Settings → Audio, set the audio controller to ICH AC97 if you want startup sound.

Put the ISO in the virtual optical drive and start the VM.

Choose Set Up This Computer to install, or Try It Without Installing.

After installing, remove the ISO or put the hard disk first in the boot order.
